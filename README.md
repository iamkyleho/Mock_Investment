# MOCK EXCHANGE · Mock Investment

검은 트레이딩 터미널, 빨강·파랑 캔들, 실시간으로 움직이는 가상의 시장. **MOCK EXCHANGE는 10만 원으로 시작하는 브라우저 모의투자 게임**입니다.

국내와 해외의 대표 종목을 골라 HIGH / LOW 포지션을 열고, 레버리지를 조절하며 계좌를 키워 보세요. 자산을 모두 잃으면 마지막 기회가 주어집니다. 10만 원을 빌린 뒤 제한 시간 안에 갚지 못하면 빨간 **DEAD** 화면과 함께 게임이 끝납니다.

## 웹에서 플레이

**[MOCK EXCHANGE 바로 플레이](https://iamkyleho.github.io/Mock_Investment/)**

설치 없이 PC나 모바일 브라우저에서 접속해 플레이할 수 있습니다. GitHub 저장소는 소스 코드를 확인하는 곳이며, 위 GitHub Pages 주소가 실제 게임 주소입니다.

GitHub Pages는 `main` 브랜치의 루트(`/`)를 웹사이트로 자동 게시합니다. 변경 사항을 올리면 웹 주소에 반영되며, 게시 진행 상황은 저장소의 **Actions → pages build and deployment**에서 확인할 수 있습니다. JavaScript 검사와 테스트는 별도의 **Check and test** 워크플로에서 실행합니다.

진행 상황은 접속한 주소와 브라우저별로 저장됩니다. 로컬 실행에서 플레이한 기록은 웹 주소로 자동 이전되지 않습니다.

## 로컬 실행

Node.js 20 이상이 필요합니다. 추가 패키지 설치나 빌드 과정은 없습니다.

Windows에서는 **`시작.bat`을 더블 클릭**해도 실행됩니다.

```powershell
cd D:\모의투자
npm start
```

브라우저에서 **http://localhost:4173**을 엽니다. 종료하려면 터미널에서 `Ctrl+C`를 누르세요. 다른 포트가 필요하면 PowerShell에서 다음과 같이 실행합니다.

```powershell
$env:PORT = 4174
npm start
```

`index.html` 파일을 직접 더블 클릭하면 브라우저의 ES 모듈 정책 때문에 실행되지 않을 수 있으므로 위의 로컬 서버를 사용하세요.

## 플레이 방법

1. 종목 목록에서 국내·해외 종목을 선택합니다.
2. **HIGH**는 가격 상승에, **LOW**는 가격 하락에 투자합니다.
3. **1원 이상**의 투자금과 **1배~100배 레버리지**를 정한 뒤 주문합니다. 투자금은 포지션의 증거금이며, 실제 가상 노출 금액은 투자금 × 레버리지입니다.
4. 포지션의 실시간 손익을 확인하고 원하는 시점에 청산합니다. 가격 변동으로 인한 손실이 증거금에 도달하면 강제 청산됩니다. 진입 수수료는 별도로 차감됩니다.
5. 1분·3분·5분 등의 차트 주기를 바꿔 캔들을 확인합니다. 1분은 실제 1분 단위의 캔들이며, 가격은 1초마다 움직입니다. 표시 주기를 바꿔도 시장은 계속 움직입니다.

진입 수수료는 포지션 규모의 **0.05%**입니다. 예를 들어 1만 원을 10배로 투자하면 포지션 규모는 10만 원, 수수료는 50원입니다. 주문에는 투자금과 수수료를 합한 현금이 필요합니다.

계좌 잔액과 투자금, 손익은 게임 안에서 원화로 계산합니다. 해외 종목의 차트에는 해당 시장의 통화 기호가 표시되지만, 주문은 원화 투자금과 가격 변동률을 기준으로 처리합니다. 실제 환율이나 시장 가격과 연결되지 않습니다.

## 마지막 기회: 빚과 GAME OVER

- 시작 자금은 **₩100,000**입니다.
- 총 평가자산이 최소 주문금액인 **1원 미만**이 되면 자산이 소진된 것으로 처리하고, 빚을 사용할지 선택하는 창을 표시합니다.
- 빚은 게임당 **한 번**, **₩100,000**을 빌릴 수 있습니다.
- 상환 기한은 **실제 시간 기준 5분**입니다. 브라우저를 닫거나 새로고침해도 기한은 늘어나지 않습니다.
- 만기에는 보유 포지션을 자동 정산해 빚을 갚습니다. 정산 후에도 10만 원이 부족하면 **DEAD / GAME OVER** 화면이 표시됩니다.
- 새 게임을 시작하면 자금과 거래 기록, 빚 상태가 초기화됩니다.

진행 상황은 현재 브라우저의 `localStorage`에 자동 저장됩니다. 시크릿 모드, 사이트 데이터 삭제, 다른 브라우저·포트에서는 기존 진행 상태를 사용할 수 없을 수 있습니다.

## 가상 시장

한국·미국·일본·홍콩·유럽의 대표 종목 **72개**를 수록합니다. 종목명은 실제 기업을 참고하지만, 모든 가격·거래량·차트·시장 이벤트는 무작위 시뮬레이션입니다. 전체 거래소의 모든 상장 종목을 제공하는 서비스는 아닙니다.

이 프로젝트는 실제 거래, 증권 계좌 연결, 입출금, 실시간 시세 API를 사용하지 않습니다. 화면의 투자금과 대출은 모두 게임 내 가상 자금입니다.

## 구성

```text
index.html                 화면 구조
styles.css                 터미널 UI와 반응형 스타일
src/app.js                 화면 갱신, 주문, 이벤트 처리
src/engine.js              가격 시뮬레이션과 계좌·포지션·빚 규칙
src/stocks.js              국내·해외 종목 목록
src/chart.js               실시간 캔들 차트
scripts/serve.mjs          외부 의존성 없는 로컬 HTTP 서버
tests/                     게임 규칙 테스트
.github/workflows/ci.yml   JavaScript 검사와 자동 테스트
```

HTML, CSS, JavaScript ES 모듈만 사용합니다. 로컬 서버는 `127.0.0.1`에 바인딩하고, 프로젝트 밖의 파일과 `.git` 등의 숨김 경로 접근을 차단합니다. 웹에서는 GitHub Pages가 정적 파일을 제공하며 별도의 게임 서버는 필요하지 않습니다.

## 검증

```powershell
npm run check
npm test
```

`check`는 JavaScript 구문을 확인하며, `test`는 Node.js 내장 테스트 러너로 모의투자 엔진의 거래와 손익, 청산, 빚, 저장 상태 등의 동작을 검증합니다.

23개 엔진 테스트와 데스크톱·모바일 브라우저에서 주문, 청산, 검색, 대출, 상환, 만기 실패, 새로고침 복구를 검증했습니다.
